Sortare care alege un pivot și împarte elementele în mai mici și mai mari decât el | Quicksort | Inventat de Tony Hoare în 1959-1960. | Quicksort | | | Sortare rapidă

Complexitatea unui algoritm care face aceeași operație indiferent de mărimea datelor | Timp constant | Se scrie O(1). Exemplu: accesarea unui element dintr-un vector după index. | Constant time, O(1)

Metoda care salvează rezultatele subproblemelor ca să nu le calculeze de mai multe ori | Programare dinamică | Exemplu clasic: șirul lui Fibonacci calculat rapid. | Dynamic programming

Algoritm care găsește cel mai scurt drum într-un graf cu distanțe pozitive | Dijkstra | Publicat de Edsger Dijkstra în 1959. Folosit și de aplicațiile de navigație. | Dijkstra's algorithm

Parcurgerea unui graf mergând cât mai adânc pe o ramură înainte de a reveni | DFS | Depth-First Search - parcurgere în adâncime. | Depth-first search | | | Parcurgere în adâncime
Algoritmul antic pentru cel mai mare divizor comun a două numere | Algoritmul lui Euclid | Descris de Euclid în jurul anului 300 î.Hr. | Euclidean algorithm
Șirul în care fiecare termen e suma celor doi dinainte: 0, 1, 1, 2, 3, 5, 8... | Fibonacci | Exemplu clasic de recursivitate. | Fibonacci sequence | | | Șirul lui Fibonacci

~ Compilator ~ Interpretor ~ Compilatorul traduce tot programul înainte. Interpretorul execută linie cu linie.
~ Stivă ~ Coadă ~ Stiva: ultimul intrat iese primul (LIFO). Coada: primul intrat iese primul (FIFO).
~ Căutare liniară ~ Căutare binară ~ Liniară: verifici pe rând, merge pe orice listă. Binară: înjumătățești, dar lista trebuie sortată.
~ Clasă ~ Obiect ~ Clasa e șablonul. Obiectul e exemplul concret creat după el.
~ BFS ~ DFS ~ BFS: nivel cu nivel. DFS: cât mai adânc pe o ramură.
~ Merge sort ~ Quicksort ~ Merge sort împarte în jumătăți și interclasează. Quicksort alege un pivot și împarte după el.
~ Eroare de sintaxă ~ Eroare de logică ~ Sintaxa greșită oprește programul. Logica greșită dă rezultate greșite, fără mesaj.
~ HTML ~ CSS ~ HTML: structura (ce e pe pagină). CSS: aspectul (cum arată).
~ Front-end ~ Back-end ~ Front-end: în browser. Back-end: pe server.
~ Java ~ JavaScript ~ Limbaje diferite, cu nume asemănătoare. Java: aplicații și servere. JavaScript: paginile web.
~ Commit ~ git push ~ Commit-ul salvează local. Push-ul trimite pe server.
~ Vector ~ Listă înlănțuită ~ Vectorul: acces rapid după poziție. Lista înlănțuită: inserare ușoară la mijloc.
